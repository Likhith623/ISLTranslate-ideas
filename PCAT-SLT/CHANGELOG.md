## 0.2.0

Implemented exact prefix-area interval extraction with a clipping oracle/fallback, shared-clock multiscale tokens, normalized-progress augmentation, bounded metric conditioning, optional unprojected full-frame detail/timing memory, padding-safe reference fallback and strict UTF-8 generation. Added exact source-group leakage checks, selectable float64 integration, matched configuration controls, expanded proofs and a limitation-by-limitation audit.

Checkpoint format is now 2. Version 0.1 weights require the preserved original source release because the metric parameterization changed. Existing historical run weights/data were not overwritten. Original verification artifacts are retained under `reports/v1/`.

The current source remains a research implementation with CPU evidence and synthetic sanity experiments. No real-corpus SOTA or publication-level novelty claim has been added.

## 0.3.0

Addressed the supplied audit with actual RGB/CNN/DINOv2 input, optional pretrained T5/mT5 text, portable tokenizer/model checkpoints, dual moving/global body coordinates, local clock streams, bounded-dimensional area sketches, per-example adaptive cells and solve-free norm-preserving palindromic rotations. Kept exact Cayley and invariant reference configurations as controls. Added annotation importers for PHOENIX-2014T, ISLTranslate and CSL-Daily, explicitly rejecting CISLR as sentence translation.

Follow-up fixes include zero-progress visual temporal binding, common-origin RGB timing checks, spatial visual pooling/calibration, explicit unanchored RGB fallback, masking unobserved motion, RGB leakage checks, one-dimensional rotations and ablation-configuration interaction validation. Format-3 checkpoints include active pretrained weights, architecture snapshots and tokenizer files; format-2 byte references remain supported. MPS integration has an explicit CPU route and a skipped hardware test on this host, not a verified acceleration claim.

Original source archives/results are preserved. Failed and final pixel diagnostics are recorded separately; no natural-language SLT performance or publication claim is inferred from them.
