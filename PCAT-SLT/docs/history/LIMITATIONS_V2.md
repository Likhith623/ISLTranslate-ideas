# Limitation-by-limitation resolution audit

This matrix describes actual v0.2 behavior. “Resolved” means the particular implementation or representation defect has a tested remedy; it does not imply that all translation errors associated with that topic are solved.

| Original limitation | V0.2 action and evidence | Status and precise remaining boundary |
|---|---|---|
| Rescanning every frame for every progress cell | One prefix-signature pass plus exact interval extraction; independent oracle/gradient agreement tests; measured CPU benchmark | **Resolved algorithmic redundancy.** Dense prefix storage and decoder work remain; no global end-to-end speedup claim. |
| Fine cells lose cross-boundary areas | Shared-clock pyramid includes a whole-clip cell and local scales; explicit boundary-alignment counterexample test | **Resolved for supplied scale coverage.** Finite temporal localization remains coarse and can still lose distinctions. |
| Retracing can erase low-order signatures | Add monotone normalized progress; test separates 0→1→0 from 0→-1→0 at equal length | **Mitigated, not universally solved.** Finite moments remain noninjective over arbitrary paths. |
| Learned diagonal metric can approach an arbitrarily bad condition number | Bounded log-weights, explicit kappa bound, extreme-parameter regression test | **Resolved for the clock metric.** Projection nullspaces, detector noise and near-zero total-motion sensitivity are different issues. |
| Learned rank-r projection discards fine shape | Enhanced detail tokens retain the entire canonical coordinate/confidence vector in an unprojected memory subspace; exact extraction test | **Resolved as a forced pre-decoder compression loss for observed numeric inputs.** Decoder attention may ignore it; estimated pose can already be wrong or incomplete. |
| Fixed K cannot represent arbitrarily detailed/long input | Enhanced memory retains every admitted original frame with padding masks; avoids detail self-attention | **Resolved fixed-token bottleneck in enhanced mode.** Explicit frame/target admission limits and decoder cross-attention cost remain. Coarse-only mode retains finite compression. |
| Common-speed invariance removes duration and holds | Enhanced mode preserves coarse durations and frame-level relative sample times; invariant mode remains available separately | **Resolved forced duration erasure in enhanced memory.** Learning correct linguistic use of duration requires data; physical timing and exact speed invariance cannot both be imposed universally. |
| First-frame anchor dropout rejects a usable clip | First reliable nondegenerate reference policy, loader/model consistency, fallback/padding tests | **Resolved when another suitable reference exists.** No reliable anchor anywhere remains an observation failure; noisy confidence can select a poor frame. Fallback can change under resampling. |
| Monocular 2D projection is ambiguous | Require explicit 3D input contract and qualify camera claims | **Not solvable from identical ambiguous observations.** Need depth, calibrated views, priors or a separately evaluated reconstruction method. |
| Landmark-only input omits RGB texture and some mouthing/gaze cues | Preserve all supplied face/hand coordinates and confidence; document the input boundary | **Unsolved sensory-information limitation.** Requires additional observations and a validated visual extension. No invented feature branch or promised recovery of unseen detail. |
| Imputation and detector jitter contaminate motion | Confidence is retained explicitly; absence is marked; bounded metric prevents arbitrary anisotropy; alternate precision/backend options | **Partially mitigated.** No guarantee of denoising, calibrated uncertainty or true missing-motion recovery. Confidence changes can influence the learned path clock. |
| Numerical prefix cancellation | Float64 integration in recommended configs, selectable explicit clipping oracle, measured FP32/FP64 disagreement | **Managed numerical tradeoff.** Neither backend nor finite precision is perfect on arbitrary dynamic ranges. Validate on actual data; float64 costs memory and GPU throughput. |
| Decoder can generate invalid UTF-8 | Budget-aware finite-state byte mask, strict Unicode range tests and randomized budget tests | **Resolved encoding-validity defect.** Does not ensure EOS, grammaticality, the requested language, truth or translation adequacy. |
| Text decoder is trained from scratch with long byte sequences | Self-contained implementation retained; strict byte validity added | **Unsolved language-model/sample-efficiency tradeoff.** Pretrained/subword extensions need controlled comparisons; adding a large decoder is not operator novelty. |
| Independent articulator timing can be meaningful | Shared clock and joint areas retain some coordination; independent-warp counterexamples remain | **Correct design choice retained.** Finite areas do not measure every type of synchronization or literal elapsed lag. |
| Area/Cayley map is not an exact path-development homomorphism | Keep correct ordered-area identity and avoid that claim | **Claim corrected, not a missing functionality.** Q of concatenated area generally differs from a product of separate Q matrices. |
| Offline global progress is noncausal | Explicit offline model; detail memory does not change that assumption | **Unsolved for streaming deployment.** A streaming formulation needs a separate clock/window policy and latency study. |
| Source-recording leakage not checked automatically | When `source_video` or `split_group` is provided, reject overlaps across train/val/test; regression test | **Resolved for supplied exact group IDs.** Unknown provenance, near duplicates and incomplete metadata still need curation. |
| Production execution was only CPU verified | Expanded CPU checks, exact resume for both regimes, archive/build verification | **CPU evidence only.** CUDA AMP, distributed training, throughput/memory at scale and deployment behavior still need target-hardware validation. |
| Novelty and superior SLT quality unverified | Preserve primary-source novelty audit and matched ablation protocol; do not relabel synthetic codes as sign language | **Unsolved empirical/research requirement.** Licensed real corpora, strong baselines, independent review and fluent-signer analysis are necessary. |

## Why “all limitations solved” would be a false research claim

Projection and missing observations create nonidentifiability: two physical situations can supply identical input tensors while requiring different target interpretations. Every deterministic model receives the same evidence in those cases. More computation cannot establish which unseen situation occurred. Additional observations or explicit assumptions are necessary.

Likewise, a representation that is invariant to a timing change cannot simultaneously distinguish every semantic distinction encoded by that exact timing change. V0.2 makes this tradeoff explicit through separate invariant and timing/detail regimes.

Finally, code and theorems can establish properties of the specified operator. They cannot establish better real-world translation or publication-level originality without the experiments and prior-art scrutiny those claims require. The current release addresses engineering defects and several representation counterexamples while leaving these scientific requirements visible.
